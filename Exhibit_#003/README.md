### Exhibit_003: MegaDateTime

A calendar that refuses to retire at year 9999, plus free public clocks for “what time is it?” and “how is Earth spinning?”, and an optional PyVista globe that will spin until you tell it not to. Left-click once to hush the captions; the sim-time HUD, the little squares, and the axes keep their posts.

```bash
pip install -e ".[viewer]"
python -m EarthViewer.main
```
