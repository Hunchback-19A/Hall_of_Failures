## Exhibit_005: Ranvier
A fictional programming language for writing models of brain-related information — named for the node of Ranvier, the gap in myelin where a signal is renewed rather than assumed. It is a strict laboratory notebook, not a brain, not a chip, and not an interface: you may record anatomy, networks, measurements, and guesses; but the compiler will not let a region become a talent, a mood become a person, or a forecast become a fate. 

Press F5 to run Axon the editor. It will report that no biological interface was detected, and that zero prophecies were compiled. 

Python 3.10 or newer; nothing else to install.

```bash
python -m axon
python -m ranvier examples/infant.cog
```
