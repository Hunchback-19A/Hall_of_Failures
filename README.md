# Hall of Failures

A collection of Python scripts born from curiosity and the occasional boredom of existence.

Welcome to the **Hall of Failures**.

This repository contains small experiments, unusual prototypes, and automation ideas created from curiosity and the desire to explore what can be built.

Some scripts solve problems.

Some scripts create new problems.

Some scripts simply become interesting failures.

All of them started with the same question:

> “What happens if I try this?”

## Philosophy

Failure is not the opposite of progress.

A failed attempt can reveal:

- hidden assumptions
- unexpected behaviors
- new ideas
- better questions

The goal of this repository is not to collect broken things, but to preserve the experiments that taught something along the way.

## Exhibits

Each exhibit is a small artifact:

- a script
- a prototype
- an automation attempt
- or an idea that was too interesting not to build

Some may become useful tools.

Some may remain experiments.

Both belong in the Hall of Failures.
